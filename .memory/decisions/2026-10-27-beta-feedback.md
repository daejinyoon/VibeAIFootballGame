# Decisions: Football Beta Feedback

- Date: 2026-10-27
- Status: Confirmed

## D01. Beta 표시
- **Chosen**: 시작 화면에만 `BETA` 배지를 표시한다. 패키지 버전은 변경하지 않는다.
- **Rationale**: 사용자는 버전을 베타로 표시하되, 표시 범위로 시작 화면을 선택했다.

## D02. 경기 멈춤 조사
- **Chosen**: PC Chrome/Edge에서 몇 분 플레이한 뒤 브라우저 탭 전체가 응답하지 않는 현상을 우선 대상으로 삼아 원인을 조사하고 안정성을 개선한다.
- **Rationale**: 보고된 증상이 경기 화면에 한정되지 않고 탭 전체에 영향을 주며, 지속 플레이 후 발생한다.
- **Known reproduction details**: 특정 경기 이벤트나 정확한 재현 순서는 아직 알려지지 않았다.

## D03. 플레이어 입력 지연
- **Chosen**: 이동·패스·슛·스킬 등 플레이어의 조작 입력 반응을 개선한다.
- **Rationale**: 사용자가 말한 약 1초 지연은 상대 AI나 HUD가 아니라 플레이어 입력에 해당한다.

## D04. 일반 슛 궤적
- **Chosen**: 슛 게이지는 추가하지 않는다. 가까운 슛은 빠르고 낮게, 먼 슛은 더 높은 포물선으로 날리며 중간 거리는 부드럽게 보간한다.
- **Rationale**: 사용자는 충전 게이지를 원하지 않고, 거리별 궤적 차이를 원한다.

## D05. 선수 다리 잘림
- **Chosen**: 이번 작업 범위에서 보류한다.
- **Rationale**: 사용자가 이 문제는 나중에 다루자고 명시했다.

## D06. 골킥 안내
- **Chosen**: 이미 구현된 골킥 규칙은 유지하고, 경기에서 골킥 상황과 조작 안내가 더 잘 보이도록 개선한다.
- **Rationale**: 사용자는 골킥이 없다는 피드백을 실제 규칙 부재가 아니라 상황이나 안내를 알아보기 어려운 문제로 확인했다.

## D07. 관중 모션과 함성
- **Chosen**: 관중 모션은 골이 났을 때만 재생한다. 녹음된 `Strong cheering II - Short` 클립 하나를 킥오프와 골 때 재생하고, 골에서는 더 크게 들리게 한다. 클립은 OpenGameArt의 Gregor Quendel 음원 모음에서 가져오며 CC BY 4.0 출처 표시를 포함한다.
- **Rationale**: 사용자는 관중 모션을 골에만 원했고, 킥오프와 골에는 함성을 원했으며, 골의 반응은 더 크게 하기로 했다.
- **Asset**: https://opengameart.org/content/free-crowd-cheering-sounds

## D08. 입장 음악
- **Chosen**: UEFA Champions League 또는 Europa League의 공식 곡과 그 멜로디를 편곡한 버전은 사용하지 않는다. 대신 UEFA 멜로디를 포함하지 않는 독창적인 아케이드 입장 팡파르를 사용한다.
- **Rationale**: 사용자는 UEFA 사용 허가가 없다고 확인했고, 공식 규정은 대회 음악의 사용·모방·변형에 사전 서면 승인을 요구한다. 유튜브 링크를 숨은 배경 플레이어 또는 오디오 전용으로 사용하는 방식도 채택하지 않는다.
- **Source**: https://documents.uefa.com/r/Regulations-of-the-UEFA-Champions-League-2026/27/Article-12-Intellectual-property-rights-Online
- **YouTube policy**: https://developers.google.com/youtube/terms/developer-policies

## D09. 입장 음악 재생 위치와 종료
- **Chosen**: 팀 커스터마이즈와 스테이지 선택 화면 모두에서 재생한다. 두 화면을 이동할 때 재생을 이어가고, 해당 화면에 머무는 동안 반복한다. 경기에 진입하면 서서히 멈춘다.
- **Rationale**: 사용자는 두 화면 모두를 선택했고, 화면에 머무는 동안 반복한 뒤 경기 시작 때 페이드아웃하는 방식을 선택했다.

## D10. 코드베이스 근거와 범위 메모
- 현재 `game/package.json` 버전은 `0.1.0`이다. 베타 배지는 제품 화면에만 표시하고 패키지 버전은 유지한다.
- 일반 슛은 즉시 나가며, 고정 속도와 높이 0을 사용한다. 방향 및 골문 보정 로직은 기존 구조를 유지하면서 거리 기반 속도·높이를 더한다.
- `stepGame.test.js`는 즉시 슛 동작과 게이지 미충전을 명시적으로 검사한다. 게이지는 추가하지 않으며, 거리 궤적 변경에 맞춰 관련 검증을 갱신한다.
- 골킥 로직과 관련 테스트가 이미 있으므로 규칙을 중복 구현하지 않는다. UI 안내를 개선한다.
- 실제 UEFA 음악은 서면 승인이 있을 때만 다시 검토한다. 대체 음원을 YouTube 배경 재생으로 구현하지 않는다.

## 확인 필요 및 이번 결정에 포함하지 않은 저장소 사항
- `game/src/components/MiiPlayerModel.jsx`의 태클 포즈 계산은 선언되지 않은 `sliding` 식별자를 참조한다. 태클 때 렌더링 예외를 일으킬 수 있는 코드 후보이며, 멈춤 조사에서 우선 재현·확인한다. 현재 받은 피드백만으로 탭 전체 멈춤의 원인이라고 단정하지 않는다.
- 작업 트리에 기존 변경이 있다. 특히 `game/src/components/Match3DCanvas.jsx`는 그림자를 끄도록 수정되어 있다. 이를 덮어쓰거나 되돌리지 말고 성능 작업 전후 비교 시 기존 변경으로 기록한다.
- `.memory/current.md`는 별도 Cosmos DB 구성 작업의 `P02-T01`을 가리킨다. 이번 인터뷰에서는 그 포인터를 바꾸지 않았다. 이 축구 게임 작업을 계획으로 옮길 때 현재 활성 Task 포인터와 충돌하지 않도록 확인이 필요하다.
