# Decisions: 덱스 3D 아케이드 축구 게임

- Date: 2026-10-22
- Status: Confirmed
- Scope: 기존 React 축구 게임을 실제 3D 경기 화면의 오리지널 아케이드 축구 웹앱으로 발전시킨다. 우선 로그인 없이 로컬에서 1인 AI 캠페인을 플레이하고, 사내 Entra ID/Azure 연결과 온라인 대전은 후속 작업으로 둔다.
- Supersedes: 기존 2D/2.5D 시각 표현, 팀당 6명 및 3단계 캠페인, 경기당 게이지로 스킬을 사용하는 규칙을 이 문서의 결정으로 갱신한다. 아래 변경에 포함되지 않은 경기 규칙, 임시 저장·랭킹 동작은 기존 결정을 유지한다.

## D01. 앱과 개발 언어
- **Chosen**: 기존 `game/` 앱을 React와 JavaScript 기반 PC 웹앱으로 발전시킨다.
- **Rationale**: 기존 앱과 캠페인·저장 기능을 이어간다.

## D02. 3D 렌더링
- **Chosen**: React Three Fiber와 Three.js로 실제 3D 경기장·선수·공을 렌더링한다.
- **Chosen**: 높은 사선 중계 시점의 카메라가 공을 부드럽게 따라간다. 선수는 경기장 바닥의 두 축으로 이동하며 점프 높이를 따로 가진다. 공도 3차원 높이와 포물선 움직임을 가진다.
- **Rationale**: 실제 3D 장면에서 패스·점프·헤딩 경합을 표현한다.

## D03. 아트와 화면 디자인
- **Chosen**: 경기 화면은 강한 색상과 과장된 동작·스킬 연출을 쓰는 오리지널 아케이드 카툰 스타일이다. 경기장과 선수는 코드로 만든 오리지널 저폴리 모델이다.
- **Chosen**: 메뉴·랭킹·보상 화면은 DEX 고유 브랜딩을 적용한 밝고 역동적인 스포츠 게임 소개 페이지 분위기로 구성한다. 보상 카드와 선수별 장착 화면은 사용자가 첨부한 참고 이미지의 흐름을 참고한다.
- **Chosen**: Nintendo 캐릭터, 로고, 게임 에셋은 사용하지 않는다.
- **Rationale**: 참고한 게임 소개 페이지의 상쾌한 아케이드 분위기를 살리면서 독자적 디자인을 만든다.

## D04. 팀 구성과 게임 모드
- **Chosen**: 팀당 4명, 총 4대4 경기다. 각 팀은 필드 선수 3명과 골키퍼 1명으로 구성한다.
- **Chosen**: 첫 버전은 1인 플레이어 대 AI다. 직원 간 온라인 대전은 AI 버전 확인 후 별도 계획으로 개발한다.
- **Rationale**: 세 필드 선수와 골키퍼를 포함한 아케이드 축구 구성을 먼저 로컬에서 완성한다.

## D05. 5단계 캠페인
- **Chosen**: 캠페인은 총 5단계다. 1~4단계는 일반 AI 경기, 5단계는 최종 보스전이다. 각 정규 경기는 기존처럼 60초이며 동점이면 골든골을 진행한다. 승리하면 다음 단계로, 패배하면 해당 단계에 재도전한다.
- **Chosen**: AI 스킬 보유 인원은 1~5단계에 각각 0·1·2·3·3명이다. 5단계 보스는 스킬 사용과 경기 전술도 강화한다.
- **Chosen**: 기존 킥오프, 골킥, 스로인, 코너킥, 프리킥·페널티킥, 반칙·카드·퇴장 규칙과 AI 동작은 새 구성에 맞게 유지한다.
- **Rationale**: 첫 무스킬 경기부터 단계별로 강해지는 상대를 이기며 5단계 보스에 도전한다.

## D06. 스킬 종류·장착·중복
- **Chosen**: 기존 6종 스킬—독수리슛, 회오리슛, 파워 태클, 을룡타, 진공청소기, 무지개반사—을 유지한다. 골키퍼는 스킬을 사용하지 않는다.
- **Chosen**: 각 필드 선수는 한 시점에 한 종류의 스킬만 장착한다. 한 선수에게 같은 스킬 카드를 최대 3장까지 쌓을 수 있고, 보유 카드 수만큼 그 선수가 한 경기에서 그 스킬을 사용할 수 있다. 서로 다른 필드 선수에게 같은 스킬을 장착할 수 있다.
- **Chosen**: 스킬 사용에 팀 게이지를 요구하지 않는다. 카드 수가 경기당 사용 횟수 한도이며 경기 시작 시 한도가 다시 채워진다.
- **Rationale**: 보상을 한 선수에게 모아 해당 선수의 스킬 사용 횟수를 늘리는 성장을 제공한다.

## D07. 스킬 보상과 캠페인 내 보유
- **Chosen**: 첫 경기는 스킬 없이 시작한다. AI 단계를 이길 때마다 무작위 스킬 카드 3장 중 1장을 고른다. 선택한 카드는 어느 필드 선수에게든 줄 수 있으며, 원하면 캠페인 보관 목록에 둔다.
- **Chosen**: 한 선수에게 같은 스킬 카드를 추가하면 복사본이 쌓인다(최대 3장). 다른 종류 스킬을 배정하면 기존 장착 카드는 보관 목록에 돌려놓아 다시 쓸 수 있다.
- **Chosen**: 카드 보관 목록과 장착 상태는 현재 5단계 캠페인 안에서만 유지하고, 새 캠페인 시작 시 초기화한다.
- **Chosen**: 최종 5단계 승리도 스테이지 클리어 보상 선택을 제공한다.
- **Rationale**: 승리 보상 선택과 선수별 빌드 구성을 매 단계의 전략으로 만든다.

## D08. 점프·공중볼·헤딩·크로스
- **Chosen**: Space 키로 점프한다. 별도 헤딩 키는 없다. 점프 중인 선수가 공중에 뜬 공과 머리 높이에서 접촉하면 헤딩으로 처리한다.
- **Chosen**: 기존 A 로빙 패스를 유지한다. 측면에서 A로 골문 쪽에 보내는 공은 크로스로 판정해 공중 경합과 헤딩 기회를 만든다.
- **Chosen**: 아케이드 물리를 사용해 로빙 패스·크로스 공은 포물선으로 날고 선수 점프와 공 높이의 충돌을 계산한다.
- **Rationale**: 사용자가 점프 시점과 위치를 이용해 크로스 헤딩을 노릴 수 있게 한다.

## D09. 조작 방식
- **Chosen**: 방향키 이동, 공격 A 로빙 패스·크로스 / S 땅볼 패스 / D 슛, 수비 A 태클 / S 조작 선수 변경 / D 압박, F 스킬, Space 점프를 유지한다.
- **Chosen**: 기존 차기 게이지와 방향 선택·패스 등 세부 조작은 기존 구현 규칙을 따른다.
- **Rationale**: 익숙한 PC 조작을 유지하고 Space 점프를 추가한다.

## D10. 임시 저장과 랭킹
- **Chosen**: 로컬 버전은 로그인 없이 브라우저에 저장하며, 임시 캠페인 저장·불러오기·저장 후 나가기, 기존 별명과 최고 기록 랭킹을 유지한다.
- **Chosen**: 저장된 캠페인에는 현 단계, 통과 결과, 스킬 보관 카드 수, 선수별 스킬 장착과 남은 단계 상대 구성을 저장한다. 불러오면 통과한 단계는 보존하고 현재 단계 경기를 시작부터 다시 한다.
- **Chosen**: 랭킹은 최고 도달 단계가 우선이며 동률은 통과한 경기들의 누적 골 차로 정한다. 새 캠페인 스테이지 수는 5로 확장한다.
- **Rationale**: 새 성장 빌드를 중단 후에도 이어가고 기존 랭킹 기능을 유지한다.

## D11. 후속 Entra ID/Azure 및 온라인 대전
- **Chosen**: 로컬 개발에는 로그인을 요구하지 않는다. 사내 배포에서는 Azure Entra ID 로그인을 필수로 하고 덱스 테넌트의 지정 보안 그룹 구성원만 입장시킨다. 그룹 제한은 신뢰할 수 있는 서버/API에서도 확인한다.
- **Chosen**: 계정별 Azure 저장, 사내 공용 랭킹 및 Azure 서비스 선택은 로컬 3D 게임 확인 후 별도 인터뷰·계획에서 정한다. 온라인 대전도 별도 후속 단계에서 정한다.
- **Rationale**: 사용자가 우선 로컬 AI 버전을 플레이해 보기를 원한다.
