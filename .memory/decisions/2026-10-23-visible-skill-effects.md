# Decision: Make Skill Preview Effects Visible

- Direct preview entry must focus the match canvas automatically so the player can trigger the skill with F immediately.
- Tornado Shot needs a large animated funnel around the ball with rotating wind bands and rising particles; the previous small orbit particles were too subtle.
- World Split needs a clearly raised, emissive jagged wall, ground fissure glow, and visible sparks whose height reads against player models.
- Keep a longer cut-in for these large set-piece skills so their activation is easy to notice.
