# Decisions: RKO Face-Up from Start

- Date: 2026-11-02
- Status: Confirmed

## D01. Face-up timing
- **Chosen**: The finisher turns face-up as soon as the RKO approach begins, at choreography time 0.8 seconds, and stays face-up through the leap, impact, and grounded pose.
- **Rationale**: The user asked to remove the phase where the finisher points toward the ground before turning face-up. With no further timing selection, interpret “from the beginning” as the start of the finisher's RKO approach.

## D02. Recovery
- **Chosen**: Blend the finisher back to the regular celebration pose during the existing recovery interval.
- **Rationale**: Preserve the five-second celebration and existing recovery timing.
