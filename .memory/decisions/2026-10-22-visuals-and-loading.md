# Decisions: 축구 게임 시각 검수와 초기 로딩 최적화

- Date: 2026-10-22
- Status: Confirmed

## D01. 시각 검수 범위
- **Chosen**: Chrome에서 데스크톱 1440×950 및 모바일 390×844 화면으로 시작, 보상 선택·선수 배정·편성, 경기·일시정지, 랭킹 흐름을 확인한다.
- **Rationale**: 이 화면들은 캠페인의 핵심 사용자 흐름을 대표하며 좁은 화면에서의 버튼 줄바꿈과 3D 경기장 높이 문제를 확인할 수 있다.

## D02. 모바일 표시 보정
- **Chosen**: 시작 화면의 3개 액션 버튼이 작은 폭에서 한 글자씩 세로로 쌓이지 않게 하고, 모바일 3D 경기장을 세로로 과하게 늘리지 않도록 뷰포트 비율을 조정한다.
- **Rationale**: 실제 390px 화면에서 버튼 라벨이 세로로 깨지고 3D Canvas가 298×360px로 표시되어 경기장이 눌려 보였다.

## D03. 번들 최적화
- **Chosen**: `GameScreen`과 그 하위 R3F/Three.js 모듈은 경기 화면 진입 시 지연 로드한다.
- **Rationale**: 사용자가 선택한 범위다. 앱 첫 화면에는 3D 경기 엔진이 필요하지 않아 초기 JavaScript 다운로드·평가를 늦출 수 있고, 게임 실행 구조는 유지한다.

## D04. 시각 검수에서 확인한 정상 동작
- **Chosen**: 보상 카드 선택, 선수 장착, 인벤토리 재배치, 다음 경기 진입, 일시정지와 랭킹을 브라우저에서 확인하고 모바일 페이지의 가로 넘침과 런타임 오류도 확인한다.
- **Rationale**: 자동 단위 테스트만으로는 실제 레이아웃과 3D Canvas 크기를 확인할 수 없다.
