# Decisions: 덱스 픽셀 축구 게임

- Date: 2026-10-21
- Status: Confirmed
- Scope: React 기반 PC 웹 게임의 로컬 플레이 버전을 먼저 만든다. 이후 Entra 로그인과 Azure 클라우드 저장·랭킹을 연결한다.

## D01. 게임 화면과 조작 기기
- **Chosen**: 위에서 내려다보는 2D 탑다운 화면. PC 웹 브라우저를 우선 지원한다.
- **Rationale**: 사용자는 경기장에서 상·하·좌·우로 자유롭게 움직이고 싶어 한다. 6대6 경기에는 탑다운 화면이 적합하다.

## D02. 시각 스타일
- **Chosen**: 픽셀 아트 스타일. 선수, 공, 경기장 그래픽은 프로젝트 안에서 간단히 직접 만든다.
- **Rationale**: 외부 이미지 팩 없이 로컬 게임을 빠르게 만들고, 초보자가 그림 파일 준비 없이 구조를 익힐 수 있다.

## D03. 팀과 경기 구성
- **Chosen**: 골키퍼 포함 팀당 6명, 총 6대6 경기. 기본 포메이션은 골키퍼 1명, 수비수 2명, 미드필더 2명, 공격수 1명이다.
- **Rationale**: 사용자가 생각하는 6대6 구성에 맞추고, 초반 구현에서 균형 잡힌 기본 배치를 제공한다.

## D04. 경기 조작
- **Chosen**: 방향키 상·하·좌·우로 이동한다. 공 소유권에 따라 공격·수비 조작이 자동 전환된다.
- **공격 중**:
  - A: 로빙 패스
  - S: 땅볼 패스
  - D: 슛
  - 패스 키와 함께 누른 방향키로 받을 팀원을 고른다. 패스 후 조작은 패스를 받은 선수로 전환한다.
- **수비 중**:
  - A: 슬라이딩 태클
  - S: 조작 선수 전환. 골키퍼도 선택할 수 있다.
  - D: 공을 가진 상대에게 압박
- **차기 게이지**: A/S/D 패스·슛 입력을 누르고 있는 동안 게이지가 차며, 키를 놓을 때 공을 찬다. 방향키 이동은 함께 사용할 수 있다.
- **Rationale**: 공격과 수비에서 같은 키를 문맥에 맞게 사용하고, 전달할 방향과 차는 힘을 직접 조절한다.

## D05. 경기 시간과 골 규칙
- **Chosen**: 각 단계의 정규 경기는 60초다. 시간이 끝났을 때 동점이면 골든골 연장전을 진행한다.
- **Chosen**: 골이 들어가면 실점한 팀이 중앙에서 킥오프한다.
- **Chosen**: 골키퍼가 공을 잡으면 골킥으로 재개하며, 골키퍼가 공을 경기장 중앙 쪽으로 찬다.
- **Chosen**: 골이 들어가면 점수를 갱신하고 양 팀을 시작 위치로 돌린 뒤 바로 재개한다.
- **Rationale**: 짧은 한 판 안에 승패를 정하면서도 동점 경기는 한 골로 마무리한다.

## D06. 토너먼트 단계
- **Chosen**: 총 3단계다. 플레이어 팀이 이기면 다음 단계로 진행하고, 지면 현재 단계만 다시 도전한다. 보스 단계를 이기면 캠페인을 완료한다.
- **Chosen**: 1·2단계 상대 스킬 조합은 캠페인을 시작할 때 무작위로 정한다. 1단계는 6종 중 3종, 2단계는 4종, 보스는 6종 모두 사용한다. 상대 스킬 구성은 재도전·저장 후 재개에서도 캠페인 동안 유지한다.
- **Chosen**: 상대 AI는 공 소유 중 공격하고, 공이 없을 때는 자기 진영을 지킨다. 상대는 스킬 조건이 맞을 때 상황에 맞춰 사용한다.
- **Rationale**: 반복 플레이마다 조합이 달라지고, 캠페인 안에서는 같은 상대를 학습하며 재도전할 수 있다.

## D07. 선수 스킬 목록과 장착
- **Chosen**: 스킬은 총 6종이다. 각 선수는 스테이지에 들어가기 전 스킬 설정 화면에서 스킬 1개를 장착한다. 여섯 스킬은 중복 없이 한 선수씩 배정한다.
- **Chosen**: 공격수·수비수·골키퍼 구분 없이 어느 선수에게나 어느 스킬이든 장착할 수 있다. 6명 구성은 골키퍼와 필드 플레이어 모두 포함한다.
- **공격 스킬**:
  1. **독수리슛**: 골키퍼가 막지 못하는 필살 슛이다. 무지개반사가 준비되어 있으면 반사될 수 있다.
  2. **회오리슛**: 일반 수비수는 휘어 지나가지만 일반 골키퍼는 막을 수 있다. 무지개반사만 공을 상대 골문 방향으로 돌려보낸다.
- **수비 스킬**:
  3. **파워 태클**: 일정 시간 A 태클의 범위를 넓힌다. 세부 시간·범위는 로컬 프로토타입 밸런싱 항목으로 둔다.
  4. **을룡타**: 상대 선수 한 명을 2초 동안 기절시켜 움직이지 못하게 한다.
- **골키퍼 계열 스킬**:
  5. **진공청소기**: 청소기 이펙트로 공을 사용자에게 끌어당겨 잡는다. 골키퍼가 쓰면 손으로, 필드 선수가 쓰면 발앞으로 끌어온다. F 키로 발동한다.
  6. **무지개반사**: 상대 필살기가 날아오면 자동 발동한다. 스킬을 장착한 선수가 공 쪽으로 달려가 공을 쳐서 상대 골문 방향으로 되돌린다.
- **일반 스킬 발동**: F 키로 현재 조작 중인 선수의 스킬을 발동한다. 단, 무지개반사는 팀 게이지가 가득 찼을 때 상대 필살기가 오면 자동 발동한다.
- **팀 스킬 게이지**: 우리 팀이 하나의 게이지를 공유한다. 경과 시간에 따라 차고, 성공 패스·공을 빼앗는 태클·유효 슛·골키퍼 선방으로 더 빨리 찬다. 한 경기에서 좋은 플레이를 하면 2회 이상 스킬을 쓸 수 있도록 초기 밸런스를 잡고, 수치는 프로토타입에서 조정한다. 스킬 사용은 게이지를 소모한다.
- **Rationale**: 공격·수비·골키퍼 역할을 모두 지원하고, 스테이지 전 장착 설정으로 전략 선택을 제공한다.

## D08. 저장과 랭킹: 로컬 버전
- **Chosen**: 첫 로컬 버전에서는 브라우저 저장소에 임시 저장과 랭킹을 기록한다. Azure 연결 후 계정별 클라우드 저장과 전체 직원 랭킹으로 교체한다.
- **Chosen**: 계정당 저장 슬롯은 하나다. 일시정지 메뉴의 ‘저장 후 나가기’를 누르면 저장한다. 불러오면 통과한 단계는 보존하고 현재 단계 경기의 시작부터 다시 한다.
- **Chosen**: 이미 저장이 있을 때 새 캠페인을 시작하면 기존 저장을 덮어쓴다는 확인을 먼저 보여준다.
- **Chosen**: 랭킹은 별명을 사용한다. 별명은 첫 이용 때 정하고 이후 바꿀 수 있다. 직원별 최고 캠페인 기록만 저장한다. 가장 높은 단계가 우선이며, 동률은 통과한 단계 경기들의 누적 골 차이로 정한다. 재도전에서 진 경기는 골 차이에 합산하지 않는다.
- **Rationale**: Azure 계정·리소스를 아직 준비하지 않아도 로컬에서 저장과 랭킹 흐름을 직접 시험할 수 있다.

## D09. 로그인과 Azure 연결 시점
- **Chosen**: 첫 로컬 버전은 로그인 없이 플레이한다. 이후 Azure에 배포할 때 Azure Entra ID 로그인을 필수화하고 덱스 직원 계정만 허용한다.
- **Chosen**: Azure 호스팅·API·데이터베이스 구성은 로컬 플레이 버전을 만든 뒤 결정한다. 현재는 Azure 서비스 스택을 확정하지 않는다.
- **Rationale**: 우선 게임을 로컬에서 실행하고 플레이할 수 있게 한 뒤, 사내 인증과 공유 저장 기능을 별도 단계로 연결한다.

## D10. 코드 언어
- **Chosen**: React와 JavaScript로 구현한다.
- **Rationale**: 초보자가 타입 시스템을 추가로 배우지 않고 React와 게임 로직에 집중할 수 있다.

## D11. 화면 흐름과 안내
- **Chosen**: 시작 화면에서 조작법을 보여준다. 경기 전에는 스킬 설정 화면을 보여준다. 경기 중에는 일시정지 메뉴를 제공한다. 캠페인 종료 화면에는 결과와 다시 시작 동작을 제공한다.
- **Chosen**: 구현을 진행할 때 초보자도 따라갈 수 있도록 각 작업의 목적과 변경 내용을 쉬운 한국어로 설명한다.
- **Rationale**: 사용자가 게임 플레이와 함께 React·게임 로직을 단계별로 배울 수 있도록 한다.

## D12. 미정인 프로토타입 밸런스
- **Chosen**: 파워 태클의 강화 시간·범위, 팀 스킬 게이지의 정확한 충전 수치는 로컬 플레이를 보며 조정한다. 이는 기능 범위 변경이 아니라 게임 밸런스 수치 조정이다.
- **Rationale**: 실제 조작감을 확인하기 전에는 고정 수치가 적절한지 판단하기 어렵다.
