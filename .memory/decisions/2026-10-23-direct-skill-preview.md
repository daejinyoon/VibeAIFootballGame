# Decision: Direct Skill Preview Matches

- A skill preview is launched by opening `?skillPreview=<skillId>`.
- A valid skill ID starts a stage-one match immediately with that team skill at level 1; normal campaign unlocks and reward drafts are bypassed.
- Preview matches use the player's selected team branding but never write campaign progress or leaderboard records.
- Match retry retains the preview skill, and pause exit returns home without saving.
