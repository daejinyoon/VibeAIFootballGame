# Decision: 경기 오디오와 밸런스 개선

## 목적

베타 사용자 피드백을 바탕으로 경기 오디오, 골킥 연출, 득점·수비 밸런스와 킥오프 직후 적 스킬 문제를 개선한다.

## 확정 사항

### 오디오

- 로그인 완료 직후 기존 아케이드 스타일 팬페어 BGM을 시작하고, 로그아웃할 때까지 메뉴와 경기 화면에서 반복 재생한다.
- 경기 중에는 낮은 관중 웅성거림을 계속 재생하고, 킥오프와 골 장면에는 기존처럼 더 큰 함성을 덧붙인다.
- 관중 웅성거림은 반복 재생에 적합하고 사용 조건이 명확한 음원을 사용하며, 필요한 출처 표기를 저장소에 기록한다.
- 경기 화면 오른쪽 위에 전체 소리 켜기·끄기 스피커 버튼을 둔다. BGM, 관중 소리, 기존 효과음에 한 번에 적용한다.
- 음소거 선택은 현재 접속 중에만 유지한다. 다음 접속은 기본 켜짐으로 시작한다.
- 브라우저가 로그인 직후 자동 재생을 막으면 첫 사용자 입력에서 오디오를 재개한다.

### 골킥 연출

- 골키퍼가 골킥을 준비하고 차는 전용 모션을 추가한다.
- 필드 동료들이 패스를 받을 위치로 움직여 골킥 장면을 채운다.
- 현재 골킥 입력 선택은 유지한다.

### 득점과 수비 밸런스

- 현재 골 입구 유효 높이 120을 180으로 넓힌다. 공의 골 판정, 골키퍼 위치 및 세이브 범위가 변경된 골 입구와 일치하도록 조정한다.
- 스킬에 의존하지 않는 기본 수비를 강화한다. 수비수가 공을 가진 상대에게 가까이 붙으면 자동으로 태클을 시도한다.
- 경기 킥오프와 골 뒤 재개에서 공이 다시 움직인 후 3초 동안 적 팀 스킬 발동을 막는다.
- 3초가 지난 뒤 적 팀 스킬은 기존 자동 발동 방식을 유지한다.

## 범위 제외

- 슛 게이지는 추가하지 않는다.
- 이번 작업에서는 별도의 난이도 선택 메뉴를 추가하지 않는다.

## 코드 조사 메모

- `game/src/game/menuMusic.js`는 현재 팀 등록·스테이지 선택 화면에서만 짧은 생성 BGM을 재생한다.
- `game/src/game/matchAudio.js`는 킥오프와 골 이벤트 때 단발 관중 함성을 재생한다.
- `game/src/game/stepGame.js`의 `maybeUseAiSkill`은 경기 시계가 시작된 뒤 공 소유 여부를 확인하지 않고 적 스킬을 자동 발동할 수 있다. 재개 후 대기 시간을 적용한다.
- `game/src/game/stepGame.js`의 `updateAwayDefense`는 이미 근접 수비 태클 동작을 갖고 있으므로 거리·진입 조건을 확인해 일반 수비 탈취가 일관되게 동작하도록 조정한다.
- `game/src/game/constants.js`의 골 입구는 `goalTop: 210`, `goalBottom: 330`으로 높이 120이다.
- 수동 골킥은 `beginManualRestart`와 `releaseRestart` 경로를 사용하며 전용 골키퍼 모션은 아직 없다.

## 완료 기준

- 로그인 뒤 메뉴 전환과 경기 시작을 지나 로그아웃할 때까지 BGM이 이어지고, 스피커 버튼이 모든 오디오를 즉시 음소거/복구한다.
- 경기 중 관중 웅성거림이 이어지며 킥오프와 골에서 함성이 강조된다.
- 킥오프 및 골 뒤 공 재개 후 첫 3초 안에는 적 스킬이 발동하지 않는다.
- 공을 가진 상대에게 접근한 수비수가 기본 태클을 시도한다.
- 180 높이의 골 입구에서 시각적 크기와 실제 골 판정·골키퍼 반응이 일치한다.
- 골킥에서 골키퍼 킥 모션과 동료의 수신 위치 움직임이 보인다.
