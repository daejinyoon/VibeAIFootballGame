# Plan: 경기 오디오와 밸런스 개선

## Goal

로그인 후 경기 종료까지 BGM을 이어 재생하고, 경기 관중 분위기와 전체 음소거 버튼을 제공한다. 골 입구를 180 높이로 넓히고, 가까운 수비수의 기본 태클과 재개 직후 적 스킬 제한을 적용하며, 골키퍼 골킥 모션과 동료의 수신 움직임을 추가한다.

## Confirmed Decisions

- 로그인 완료 직후 팬페어를 반복 재생하고 로그아웃까지 유지한다. 경기 중에는 낮은 관중 웅성거림과 킥오프·골 함성을 함께 재생한다.
- 경기 화면 오른쪽 위 스피커 버튼 하나로 BGM, 관중 소리, 스킬 효과음을 켜고 끈다. 선택은 현재 접속에서만 유지하며 다음 로그인 때 기본 켜짐이다.
- 경기 시작 직후 자동 재생이 차단되면 첫 사용자 입력에서 오디오를 재개한다.
- 골 입구의 기존 유효 높이를 120에서 180으로 늘리고 실제 득점 판정과 골키퍼 위치를 맞춘다.
- 공을 가진 상대에게 가까이 붙은 수비수는 스킬 없이 자동 태클을 시도한다.
- 킥오프 또는 골 뒤 킥오프에서 공이 재개된 뒤 3초 동안 적 팀 스킬을 막는다. 이후 기존 자동 발동 동작을 유지한다.
- 골키퍼 준비·킥 모션을 추가하고, 양 팀 필드 선수가 골킥을 받을 위치로 움직인다. 기존 A 장거리 킥과 S 짧은 패스 입력은 유지한다.
