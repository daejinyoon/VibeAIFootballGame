# Plan: 레트로 아케이드 축구 게임플레이

## Goal
현재 로컬 React 축구 게임에 확정된 아케이드식 패스·슛 조작, 동료 선수의 무작위 지원 이동, 축구 경기 재개 규칙, 반칙·퇴장, 원근감 있는 레트로 경기 화면을 구현한다. 기존 캠페인·스킬·저장 기능과 6대6 구성을 유지하고, 매 Task의 검증 후에도 전체 Node 테스트와 Vite 빌드가 통과해야 한다.

## 계획 범위 참고
- `stepGame.js`가 경기 상태를 직접 변경하는 구조이므로 규칙 변경은 기존 상태 전이를 유지하며 한 Task씩 추가한다.
- 시간 기반 AI 이동은 테스트 재현성을 위해 경기 상태에 저장한 정수 시드 기반 의사난수 생성기를 사용한다.
- 렌더러는 현재 캔버스 960×540을 유지하고 물리 좌표는 건드리지 않는다. 원근 투영과 카메라 오프셋은 별도 렌더 상태로 계산한다.
- 팀별 퇴장 인원은 선수의 `dismissed` 상태로부터 계산한다. 별도 인원 카운터를 저장하면 퇴장 취소/중복 처리에서 실제 선수 목록과 불일치할 수 있다.

## 첫 구현에서 사용할 임시 수치
- 결정 문서에서 감각만 정하고 정확한 값을 지정하지 않은 부분은 Task 청사진에 초기 구현값으로 적었다. 공을 직접 플레이해 보고 조정할 밸런스 값이다.
- 동료 AI 목표 재선택 1.2–2.4초, 공 주변 목표 편차 x ±220 / y ±150.
- 태클 반칙 접촉 거리 22, 페널티 구역 폭·높이 기존 필드 크기 기준 132×200, 세트피스 대기 1초.
- 원근 투영의 세로 곡선 지수 1.22와 먼 쪽 배율 0.72.
- 스로인·코너 자동 배급 속도 275. 골킥 재개는 기존 1초 흐름을 사용한다.
