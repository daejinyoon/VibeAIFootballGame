# Task: T04 Crowd Cheer and Goal Reaction

## Status: done

## Goal
Play the selected recorded crowd cheer on kickoff and goals, louder on goals, and animate the existing instanced crowd seats only when a goal is scored.

## Decision Summary
- Reuse one OpenGameArt recording: `Strong cheering - II - Short` by Gregor Quendel, CC BY 4.0. Include attribution in the shipped game assets.
- Kickoff triggers audio only. Goal triggers audio plus a short seat-bounce reaction. Do not add continuous crowd ambience or animate spectators on kickoff.
- Reuse existing InstancedMesh seats; do not create one React/Three.js mesh per spectator.

## Implementation

  - `game/public/audio/ATTRIBUTION.md` :: source, creator, title, license, and source URL; new.
  - `game/src/game/audioContext.js` :: `getAudioContext`, `prepareAudioContext` — shared Web Audio context; new.
  - `game/src/game/matchAudio.js` :: `prepareMatchAudio`, `playCrowdCheer`; new.

  - `game/src/App.jsx` :: `startStage` — prepare match audio from the explicit Start Stage click; modify.

#### Details
- **Signatures & Types**:
  ```typescript
  export function getAudioContext(): AudioContext | null;
  export function prepareAudioContext(): boolean;
  export function prepareMatchAudio(): void;
  export function playCrowdCheer(eventType: 'kickoff' | 'goal'): Promise<boolean>;
  ```
- **Data & Schema Fields**:
  - Add no saved game-state fields for audio. The sound is event-driven and one-shot.
- **Execution Flow / Logic**:
  1. During implementation, download the selected OpenGameArt bundle and extract only the named short MP3 to `game/public/audio/crowd-cheering.mp3`. Do not ship the full 19.6 MB bundle.
  2. In `ATTRIBUTION.md`, write `Strong cheering - II - Short`, Gregor Quendel, CC BY 4.0, and `https://opengameart.org/content/free-crowd-cheering-sounds`.
  3. Move the existing `AudioContext` singleton/constructor fallback from `skillAudio.js` into `audioContext.js`. Preserve the `window.AudioContext ?? window.webkitAudioContext` fallback and safe `null` result if unavailable. Refactor `skillAudio.js` to import the shared getter/preparer; preserve existing skill APIs and sound scheduling.
  4. Create one module-level `HTMLAudioElement`, set `src` to `/audio/crowd-cheering.mp3` and `preload = 'auto'`, and expose explicit preparation and event playback functions.
  5. `prepareMatchAudio()` loads the element and resumes the shared Web Audio context. Call it from `startStage`, which is reached by the user-controlled stage-start action, before `setScreen('match')`.
  6. `playCrowdCheer('kickoff')` sets volume to `0.35`; `playCrowdCheer('goal')` sets volume to `0.9`. Both replay the same clip from the beginning. Catch rejected `play()` promises and return `false`; missing audio must never throw into the game loop.
  7. In `GameLoop3D`, invoke audio outside `stepGame` for `kickoff` and `goal` events only. Do not start a looping crowd track.

### I02. Animate the existing crowd instances on goals

- Related Files:
  - `game/src/components/Match3DGame.jsx` :: `Match3DGame` — own and pass a transient `crowdReactionRef`; modify.
  - `game/src/components/GameLoop3D.jsx` :: `GameLoop3D` — set/advance/clear the goal reaction timer; modify.
  - `game/src/components/Match3DCanvas.jsx` :: `Match3DCanvas` — pass the ref to the stadium; modify while preserving `shadows={false}`.
  - `game/src/components/StadiumBackdrop3D.jsx` :: `StadiumBackdrop3D`, `SideStand` — animate the existing 92-seat instanced mesh per side; modify.

#### Details
- **Data & Schema Fields**:
  ```typescript
  type CrowdReaction = { elapsedSeconds: number; durationSeconds: 1.8 } | null;
  type CrowdReactionRef = { current: CrowdReaction };
  ```
- **Execution Flow / Logic**:
  1. Keep the transient ref in `Match3DGame`; do not add it to saved campaign/profile data or structured game-state snapshots.
  2. When the event array contains `goal`, reset the ref to `{ elapsedSeconds: 0, durationSeconds: 1.8 }`. Increment elapsed time by clamped frame delta in the existing frame loop and set it to `null` at 1.8 seconds. A kickoff does not set this ref.
  3. Pass the ref through `Match3DCanvas` to `StadiumBackdrop3D` and the two `SideStand` instances.
  4. Preserve each seat's baseline instance matrix generated by the existing `useLayoutEffect`. During the 1.8-second reaction, update those same instance matrices with a vertical bounce `Math.sin(progress * Math.PI * 4 + instanceIndex * 0.37) * 0.12 * Math.sin(progress * Math.PI)`. Mark `instanceMatrix.needsUpdate = true` while animating.
  5. Restore baseline matrices when the ref clears. Do not allocate geometries/materials or call React state setters per frame.
